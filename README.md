# Briefings

Daily briefing generated by Hermes and published on GitHub Pages:
<https://kazimeirzodnowiciel.github.io/briefings/>

There are two ways to read it:

| | What it is | Who writes it |
|---|---|---|
| **App**: `app/` | The installable Android app (PWA). Renders `editions/*.json` with Today, Sports, Saved and Archive tabs. | Hand-written, in this repo |
| **Classic pages**: `index.html`, `YYYY-MM-DD.html` | Static HTML for each edition. Good for sharing links and for RSS. | Hermes, every morning |

The installed app opens `app/` (`start_url` in `site.webmanifest`). Hermes never
touches `app/`, `sw.js` or `site.webmanifest`, so its daily run can't overwrite them.

## App features

- **Today**: lead headline, live Warsaw weather (Open-Meteo), workout card, spoken
  briefing, market tiles with 14-day sparklines, the TL;DR, What changed and Following,
  sticky section chips, and story cards. Tap a story for a bottom sheet with the summary,
  why it matters, a source excerpt when Hermes scraped a relevant one, plus Read, Save and Share.
- **Sports**: Nations League and league scoreboards, NBA, and tonight's fixtures, with
  Poland matches highlighted.
- **Saved**: bookmarks, stored on the device.
- **Archive**: every edition, plus full-text search across all of them.
- Reading progress: read stories dim, each section shows a read count, and a progress bar sits under the app bar.
- Audio player: background playback, lock-screen controls, 1–2× speed, remembers your place.
  Warns when `audio/today.mp3` wasn't regenerated for today's edition.
- New-edition check whenever the app comes back to the foreground.
- Light and dark themes, three text sizes, compact layout.
- Foldables: navigation rail and two-column layout from 840px wide (the Fold inner screen).
- Offline: the app shell is precached, editions are cached as you read them, and article images are cached up to 80.
- Push: same VAPID key and Hermes 08:45 canary as before. Taps on notifications open the app.

## Data contract with Hermes

The app reads only these files, so keep their shape stable:

- `feed.json`: the latest edition, same schema as below.
- `editions/YYYY-MM-DD.json`: `{schema, generated, date, greeting, title, workout, audio, read_minutes, sections[]}`.
  Each section is `{name, kind: stories|scores|fixtures, items[]}`.
  Each item is a story `{headline, summary, matters, url, source, image, body, day, paywall}`,
  a score `{group, home, away, home_score, away_score, note, flag}`, a fixture `{text: "Comp — line"}`
  or a note `{text}`.
- `archive.html`: the edition list. The app reads `a[href$=".html"] .t2`.
- `audio/today.mp3`.

Section roles come from section names (TL;DR, What changed, Following, Long read), and the
market tiles come from the first line of Money (`WIG20 4,302.0 · USD/PLN 3.996 (+0.04%) · …`).

## Suggested Hermes-side fixes

These are in Hermes' generator, not in this repo:

1. **Pull before push.** Hermes now shares `main` with hand-written changes. Make sure its publish step does
   `git pull --rebase` (or uses the Contents API) so a non-fast-forward never blocks a morning edition.
2. **Stale audio.** `audio/today.mp3` wasn't updated on 6, 8 and 16 Nov, so the old audio played as
   today's. Write `audio/YYYY-MM-DD.mp3` and put that path in the edition's `audio` field. The app
   already follows the field. Prune files older than about 7 days.
3. **Repo growth.** The mp3 (~800 KB) and `og.png` (~100 KB) are committed daily: `.git` is already 11 MB after two weeks.
   Dated, pruned audio helps. Release assets or an orphan branch would stop the growth completely.
4. **Structured fields.** Add `markets: [{name, value, change_pct}]` and `weather` to the JSON instead of only
   rendering them into HTML. The app parses the Money line today, which is brittle.
5. **Parsing slips**: away teams keep a trailing full stop (`Scotland.`). One NBA result per day arrives as
   a `note` instead of a `score`. The app works around both.
6. **`body` quality.** About a third of scraped bodies are page chrome or a different article. For example, the Wall Street
   story on 16 Nov carried a celebrity obituary. The app only shows a body when it matches the headline, but filtering at the source is better.
7. **OG image**: the title is cut mid-sentence and overlaps the greeting line.
8. `manifest.json` (the 3 Nov edition index) is stale and unused. It can be deleted.
